## 🚀 Local Development Setup

To run the web app locally on your machine:

1. **Clone the Repository**:
   ```bash
   git clone https://github.com/svreddy313-dev/WORLD-WIDE-.git
   cd WORLD-WIDE-
   ```

2. **Launch Local Server**:
   Using Python:
   ```bash
   python -m http.server 8085
   ```
   Or using Node `serve` / VS Code Live Server:
   ```bash
   npx serve -l 8085
   ```

3. **Open in Browser**:
   Navigate to `http://localhost:8085/index.html` in Chrome, Edge, Safari, or Firefox.
